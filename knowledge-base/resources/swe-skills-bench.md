# SWE-Skills-Bench: Do Agent Skills Actually Help in Real-World Software Engineering?

arXiv paper reference. Directly relevant to this repository's subject matter (a
catalog of agent skills): pairing 49 public SWE skills with pinned GitHub
repositories across ~565 task instances, it finds an average gain of only +1.2%,
token overhead ranging up to a 451% increase at unchanged pass rates, and three
skills that actively degrade performance through version-mismatched guidance.

[SkillsBench: Benchmarking How Well Agent Skills Work Across Diverse Tasks](/resources/skillsbench.md).
