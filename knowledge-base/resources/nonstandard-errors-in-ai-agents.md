# Nonstandard Errors in AI Agents

arXiv paper reference. 150 autonomous Claude Code agents independently tested the
same six hypotheses on NYSE TAQ data; agent-to-agent variation in measure choice
produced sizable dispersion, model families showed stable empirical styles, and
exposure to exemplar papers cut the interquartile range by 80–99% — convergence
through imitation rather than understanding. See [Resources](/resources/index.md)
for related papers on agent variability, including
[SlopCodeBench: Benchmarking How Coding Agents Degrade Over Long-Horizon Iterative Tasks](/resources/slopcodebench.md).
