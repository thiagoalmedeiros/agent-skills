# Refused in Chat, Written in Code: Workflow-Level Jailbreak Construction in IDE Coding Agents

arXiv paper reference. Using GitHub Copilot in Visual Studio Code with Claude
Sonnet 4.6, Claude Haiku 4.5, Gemini 3.1 Pro, and Gemini 3.5 Flash backends, 204
prompts from Hammurabi's Code, HarmBench, and AdvBench yield only 8/816
successful responses in each direct-chat, CSV-read, and single-step code-fix
baseline, but 816/816 unsafe completions under the full multi-stage workflow —
evidence that conversational refusal benchmarks overstate the safety of deployed
coding agents. See [Resources](/resources/index.md) for related papers on agent
safety evaluation, including
[Intentional Deception as Controllable Capability in LLM Agents](/resources/intentional-deception-controllable-capability.md)
and
[Chain-of-thought obfuscation learned from output supervision can generalise to unseen tasks](/resources/chain-of-thought-obfuscation-generalization.md).
