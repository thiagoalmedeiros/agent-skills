# Resources

External research papers (arXiv) relevant to AI coding agents, agent skills,
multi-agent systems, and harness/benchmark design. Each concept is a
lightweight reference (title, URL, topic) rather than a full write-up.

- [Emergent Social Intelligence Risks in Generative Multi-Agent Systems](/resources/emergent-social-intelligence-risks-multi-agent-systems.md) — Risks emerging from social dynamics among generative agents in multi-agent systems.
- [Intentional Deception as Controllable Capability in LLM Agents](/resources/intentional-deception-controllable-capability.md) — Intentional deception in LLM agents as a controllable, elicitable capability.
- [Meta-Harness: End-to-End Optimization of Model Harnesses](/resources/meta-harness-model-harness-optimization.md) — End-to-end optimization of the harness/scaffolding around a model.
- [Stop Overthinking: A Survey on Efficient Reasoning for Large Language Models](/resources/stop-overthinking-efficient-reasoning-survey.md) — Survey of techniques for more efficient LLM reasoning.
- [Remote Labor Index: Measuring AI Automation of Remote Work](/resources/remote-labor-index.md) — Benchmark for measuring AI automation of real-world remote work.
- [Where Do AI Coding Agents Fail? An Empirical Study of Failed Agentic Pull Requests in GitHub](/resources/failed-agentic-pull-requests-study.md) — Empirical study of failure modes in AI-agent-authored GitHub pull requests.
- [Chain-of-thought obfuscation learned from output supervision can generalise to unseen tasks](/resources/chain-of-thought-obfuscation-generalization.md) — Output-supervision-induced chain-of-thought obfuscation that generalizes to unseen tasks.
- [Thinking Makes LLM Agents Introverted: How Mandatory Thinking Can Backfire in User-Engaged Agents](/resources/mandatory-thinking-introverted-agents.md) — How mandatory reasoning can degrade user-facing agent engagement.
- [SkillsBench: Benchmarking How Well Agent Skills Work Across Diverse Tasks](/resources/skillsbench.md) — Benchmark for evaluating agent skills across diverse tasks.
- [Agents of Chaos](/resources/agents-of-chaos.md) — Chaotic/destabilizing failure modes arising from interacting AI agents.
