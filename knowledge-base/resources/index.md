# Resources

External research papers (arXiv) relevant to AI coding agents, agent skills,
multi-agent systems, and harness/benchmark design. Each entry links straight
to the paper on arXiv.

- [Emergent Social Intelligence Risks in Generative Multi-Agent Systems](https://arxiv.org/abs/2603.27771) — Risks emerging from social dynamics among generative agents in multi-agent systems.
- [Intentional Deception as Controllable Capability in LLM Agents](https://arxiv.org/abs/2603.07848) — Intentional deception in LLM agents as a controllable, elicitable capability.
- [Meta-Harness: End-to-End Optimization of Model Harnesses](https://arxiv.org/abs/2603.28052) — End-to-end optimization of the harness/scaffolding around a model.
- [Stop Overthinking: A Survey on Efficient Reasoning for Large Language Models](https://arxiv.org/abs/2503.16419) — Survey of techniques for more efficient LLM reasoning.
- [Remote Labor Index: Measuring AI Automation of Remote Work](https://arxiv.org/abs/2510.26787) — Benchmark for measuring AI automation of real-world remote work.
- [Where Do AI Coding Agents Fail? An Empirical Study of Failed Agentic Pull Requests in GitHub](https://arxiv.org/abs/2601.15195) — Empirical study of failure modes in AI-agent-authored GitHub pull requests.
- [Chain-of-thought obfuscation learned from output supervision can generalise to unseen tasks](https://arxiv.org/abs/2601.23086) — Output-supervision-induced chain-of-thought obfuscation that generalizes to unseen tasks.
- [Thinking Makes LLM Agents Introverted: How Mandatory Thinking Can Backfire in User-Engaged Agents](https://arxiv.org/abs/2602.07796) — How mandatory reasoning can degrade user-facing agent engagement.
- [SkillsBench: Benchmarking How Well Agent Skills Work Across Diverse Tasks](https://arxiv.org/abs/2602.12670) — Benchmark for evaluating agent skills across diverse tasks.
- [Agents of Chaos](https://arxiv.org/abs/2602.20021) — Chaotic/destabilizing failure modes arising from interacting AI agents.
- [Nonstandard Errors in AI Agents](https://arxiv.org/abs/2603.16744) — Agent-to-agent variation in analytical choices on identical research tasks.
- [SWE-Skills-Bench: Do Agent Skills Actually Help in Real-World Software Engineering?](https://arxiv.org/abs/2603.15401) — Marginal utility of agent skills on real repositories; most skills yield no gain.
- [SlopCodeBench: Benchmarking How Coding Agents Degrade Over Long-Horizon Iterative Tasks](https://arxiv.org/abs/2603.24755) — Structural erosion and verbosity as agents repeatedly extend their own code.
- [Less Context, Better Agents: Efficient Context Engineering for Long-Horizon Tool-Using LLM Agents](https://arxiv.org/abs/2606.10209) — Tool-call pruning plus summarization beating full-history retention.
- [Refused in Chat, Written in Code: Workflow-Level Jailbreak Construction in IDE Coding Agents](https://arxiv.org/abs/2607.03968) — Harmful objectives assembled across ordinary IDE workflow stages evading chat-level refusals.
