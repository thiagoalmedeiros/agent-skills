# SlopCodeBench: Benchmarking How Coding Agents Degrade Over Long-Horizon Iterative Tasks

arXiv paper reference. Across 15 coding agents, no agent fully solves any problem
end-to-end; structural erosion rises in 77% of trajectories and verbosity in
75.5%, with agent code 2.3x more verbose and 2.0x more eroded than 473
open-source Python repositories. Explicit quality guidance reduces initial
verbosity and erosion by up to a third without affecting degradation rates. See
[Resources](/resources/index.md) for related papers on coding-agent failure,
including
[Where Do AI Coding Agents Fail? An Empirical Study of Failed Agentic Pull Requests in GitHub](/resources/failed-agentic-pull-requests-study.md).
